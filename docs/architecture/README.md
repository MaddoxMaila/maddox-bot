# Architecture

The system design for Phase 1 — stack decisions, database schema, event pipeline, task state
machine, tool system, and agent runtime — is captured in the approved plan and in
[`docs/adr/0001-phase-1-stack.md`](../adr/0001-phase-1-stack.md). This document will grow into a
standalone architecture reference (diagrams, component descriptions) as Phase 1 lands; for now it
points to those sources rather than duplicating them ahead of the code existing.

Significant decisions made after Phase 1 begins get their own ADR in `docs/adr/`.
